# AHMED GROUP SECURITY

بوت حماية مجموعات تيليجرام باستخدام Python ومكتبة `python-telegram-bot`.

## طريقة التشغيل للمبتدئين

يمكنك تشغيل البوت مجاناً على جهازك. لا تحتاج إلى اشتراك استضافة مدفوع؛ لكن يجب أن يبقى الجهاز متصلاً بالإنترنت والبرنامج مفتوحاً حتى يرد البوت.

### 1. أنشئ بوتاً وخذ الرمز

1. افتح تيليجرام وابحث عن `@BotFather`.
2. أرسل `/newbot` واتبع التعليمات.
3. انسخ رمز البوت. لا ترسله لأي شخص ولا تضعه داخل ملفات المشروع.

### 2. ثبّت Python وشغّل المشروع

ثبّت Python 3.10 أو أحدث، ثم افتح الطرفية داخل مجلد المشروع ونفّذ:

```bash
python -m venv .venv
```

على Windows:

```powershell
.venv\Scripts\activate
pip install -r requirements.txt
$env:BOT_TOKEN="ضع_رمز_البوت_هنا"
python main.py
```

على macOS أو Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="ضع_رمز_البوت_هنا"
python main.py
```

استبدل النص داخل علامات الاقتباس بالرمز الذي أعطاك إياه BotFather. لا تكتب الرمز في `main.py` أو تشاركه في الصور والمحادثات. في Replit احفظه في **Secrets** باسم `BOT_TOKEN`.

على جهازك، شغّل الأمرين الأخيرين في كل مرة تريد تشغيل البوت. إذا أغلقت نافذة الطرفية أو أوقفت الجهاز، سيتوقف البوت. لا توجد استضافة مجانية مضمونة تعمل إلى الأبد؛ أي خدمة استضافة قد توقف التطبيق أو تضع حدوداً على التشغيل المجاني.

### 3. أضف البوت إلى مجموعتك

أضف البوت إلى المجموعة وارفعه إلى مشرف. امنحه صلاحيات حذف الرسائل، حظر الأعضاء، وتقييد الأعضاء. يحتاج إلى صلاحية التقييد لأوامر القفل والكتم. يجب أن يبقى البرنامج عاملاً حتى يرد البوت.

## الأوامر

أوامر المشرفين تعمل فقط للمشرفين الفعليين في المجموعة:

- `/warn` — تحذير عضو؛ عند ثلاثة تحذيرات يُكتم ساعة.
- `/mute [الدقائق]` و`/unmute` — كتم العضو وإلغاء كتمه.
- `/ban` و`/unban` — حظر عضو وإلغاء حظره.
- `/lock [messages|photos|videos|stickers]` و`/unlock [النوع]` — قفل نوع الرسائل وفتحه.
- `/info` و`/admins` — معلومات المجموعة والمشرفون.
- `/game` و`/quiz` و`/points` — ألغاز وأسئلة ونقاط.
- `/help` — عرض المساعدة.

لتحديد العضو، استخدم الأمر رداً على رسالته، أو أضف رقم حسابه. يمكن استخدام الأوامر العربية بعلامة التعجب، مثل `!تحذير` و`!كتم` و`!قفل photos` و`!معلومات` و`!مساعدة`.

يحذف البوت الروابط ورسائل الإغراق تلقائياً، ويرسل ترحيباً عربياً عند انضمام عضو. تُحفظ التحذيرات والنقاط وإعدادات القفل في ملف `bot_data.sqlite3`.

يتضمن ملف ZIP الملفات الثلاثة `main.py` و`requirements.txt` و`README_AR.md` جاهزة للاستخراج.
